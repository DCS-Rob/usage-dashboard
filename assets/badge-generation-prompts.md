# Header Badge Prompts

Gebruik deze prompts als je de twee badge-plaatjes later exact wilt laten maken door Nano Banana of ChatGPT Image. Exporteer als vierkante PNG met transparante achtergrond, bijvoorbeeld 512x512, en vervang daarna:

- `assets/anthropic-ai-badge.svg`
- `assets/openai-badge.svg`

Als je PNG gebruikt, pas in `index.html` alleen de extensie aan van `.svg` naar `.png`.

## Anthropic / Claude AI Badge

Create a premium circular app badge for an AI dashboard header. Dark navy glass background, cyan neon outer ring, subtle inner ring, centered text "AI" in clean bold geometric sans-serif. Compact, high contrast, glossy but not cartoonish, designed for a 34px toolbar icon. No extra words, no watermark, transparent background.
